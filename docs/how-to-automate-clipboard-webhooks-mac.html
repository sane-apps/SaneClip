Questions

Which URL commands does SaneClip support?

history, search?q=, paste?index= (0 is the newest clip), copy?text=, snippet?name=, export and clear, each after saneclip://. Clear always asks first.

Do URL commands respect the Touch ID lock?

Yes. With the Pro Touch ID lock on, commands that need confirmation ask for Touch ID or your Mac password first.

Can a URL fill in snippet placeholders?

Yes. Add each value as a query item, for example saneclip://snippet?name=Reply&customer=Sam.
