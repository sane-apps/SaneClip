Questions

Does SaneClip detect card numbers and API keys on the Mac?

Not reliably. On the Mac it skips password-manager copies and text that looks like a password. A card number or API key copied from somewhere else can still be saved, so use auto-delete, the Touch ID lock and encryption, or press Control-Shift-Command-I before you copy, and SaneClip ignores the next copy.

How do I skip one copy without changing settings?

Press Control-Shift-Command-I before you copy. SaneClip ignores the next copy.

Does the iPhone app save sensitive data?

When you save from the Share sheet or the current iPhone clipboard, the companion won't save text that looks like a card number, Social Security number, API key, private key or password.
